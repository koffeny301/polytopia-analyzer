# Polytopia Analyzer — как пользоваться

Программа читает матч The Battle of Polytopia прямо из игры и строит по нему
отчёт: счёт и динамика по ходам, города, убийства и потери, сравнение игроков,
графики в стиле Civilization. Терминал не нужен.

Работает на Linux с нативной сборкой игры из Steam.

## Установка

1. Распакуйте архив `polytopia-analyzer-<версия>-linux-x86_64.tar.gz`.
2. Запустите `install.sh` из распакованной папки (двойной клик; если файловый
   менеджер спросит — выберите «Выполнить»). Либо пропустите этот шаг:
   программа работает и просто из папки.
3. В меню приложений появится **«Анализатор матчей Polytopia»**.

## Первый запуск

Открывается браузер с локальной страницей (адрес `127.0.0.1:8765`, никуда
в интернет данные не уходят).

## Чтение матча из игры

1. В карточке **«Чтение из игры (Steam)»** нажмите **«Включить»**.
   Программа добавит строку запуска в параметры игры в Steam и перезапустит
   Steam — иначе настройка не применится.
2. Откройте реплей: ссылка вида `share.polytopia.io/g/…` (кнопка «Играть»
   на странице ссылки) или через саму игру.
3. Во время проигрывания реплея в карточке **«Импорт из игры (шим)»**
   нажмите **«Импортировать снимки»** — матч появится в списке «Мои матчи».
4. Кнопка **«Построить отчёт»** — отчёт откроется в новой вкладке.

Чтобы выключить чтение: та же карточка → **«Выключить»** (Steam снова
перезапустится, параметры запуска вернутся как были).

## Что есть в отчёте

- итоговая таблица: счёт, прирост, убийства, потери, K/D, захваты городов;
- динамика счёта по ходам, лидеры, награды;
- города и экономика;
- графики боя.

Данные берутся из состояния игры, поэтому счёт и города точные.

## Чего в данных нет

Игра не хранит доход за ход, размер армии, захваты городов и урон — этих
метрик в матче не будет (в таблице они пустые, а не нулевые). Убийства и потери
есть: они считаются по счётчикам состояния.

## Ограничения

- **Только реплеи.** Читать состояние в живом матче — это нечестная игра,
  программа для этого не предназначена. Включайте чтение на время разбора
  реплея и выключайте после.
- Пока чтение включено, **внутриигровой оверлей Steam не работает**.
- Нужна нативная Linux-сборка игры (не Proton). Для Windows/Proton чтения
  состояния пока нет — там работает ручной ввод и OCR скриншотов.

## Удаление

- Чтение: карточка «Чтение из игры (Steam)» → «Выключить».
- Программа: `install.sh --uninstall` из папки установки.
- Данные (матчи, снимки): `~/.local/share/polytopia-analyzer` — удаляются
  вручную, если больше не нужны.

## Если что-то не так

- **«Шим не найден»** — архив распакован не полностью, распакуйте заново.
- **Матч не появляется** — реплей должен быть открыт в игре, а чтение включено;
  обновите страницу и нажмите «Импортировать снимки».
- **Steam не запустился после включения** — запустите его обычным способом,
  настройка уже сохранена.
- **В отчёте мало метрик** — это нормально, см. «Чего в данных нет».
