# Спецификация CSV (строгий формат)

Файл матча в CSV — это UTF-8 текст из трёх частей: комментарии с
метаданными, комментарии с игроками и таблица «ход × игрок». Формат
round-trip: `match_to_csv` → `match_from_csv` возвращает идентичные данные.
Парсер — `polytopia_analyzer/storage.py`; значения метрик описаны в
[metrics.md](metrics.md).

## 1. Комментарии

Строка, начинающаяся с `#` (пробелы слева допустимы), — комментарий.

### Метаданные: `# ключ: значение`

Допустимые ключи (регистр не важен): `title`, `date`, `mode`, `map`,
`link`, `turn_limit`, `notes`, `source`, `verified`. Неизвестный ключ —
ошибка загрузки. `turn_limit` приводится к целому. Все поля необязательны.

- `source` — происхождение данных: пусто (ручной ввод), `polymod`, `ocr`;
- `verified` — дата принятия предупреждений валидации (пусто = черновик).

Комментарий без двоеточия игнорируется (обычное примечание).

### Игроки: `# player: имя; племя; цвет; human`

Поля разделяются `;` и обрезаются по пробелам:

1. **имя** — обязательно, непустое, уникальное в матче;
2. **племя** — необязательно (например `Bardur`);
3. **цвет** — необязательно, hex (`#4363d8`); пустое поле = цвет не задан;
4. **human** — необязательный маркер «это человек»: `human`, `1`, `true`,
   `yes`, `да` (регистр не важен). Отсутствие = AI.

Порядок комментариев-игроков задаёт порядок игроков в отчёте.

## 2. Таблица

Первая непустая строка без `#` — заголовок. Колонки (регистр и пробелы
по краям не важны):

| Колонка | Тип | Обязательность |
|---|---|---|
| `turn` | целое ≥ 0 | обязательна |
| `player` | строка, имя из `# player` | обязательна |
| `score` | дробное | необязательна |
| `income` | дробное | необязательна |
| `army` | целое | необязательна |
| `cities` | целое | необязательна |
| `kills` | целое | необязательна |
| `losses` | целое | необязательна |
| `captured` | целое | необязательна |
| `lost_cities` | целое | необязательна |
| `damage` | дробное | необязательна |

Неизвестная колонка — ошибка загрузки. Лишние колонки не допускаются:
формат строгий, чтобы опечатка в названии не превращалась в молчаливый ноль.

### Значения

- Числа: `123`, `-4`, `2.5`; десятичная запятая допускается (`2,5` → 2.5).
- **Пустая ячейка = неизвестно**, не ноль. Пустые метрики не участвуют
  в статистике и снижают полноту данных (панель «Проверка данных»).
- Строка, у которой пусты **все** метрики, игнорируется целиком (так
  устроен шаблон с незаполненными будущими ходами).
- Дробные значения целых метрик усекаются (`2.9` → 2); лучше писать целые.
- Отрицательные метрики запрещены (ошибка валидации `E_NEGATIVE`).

### Ошибки, отклоняющие файл при загрузке

- нет табличных данных / нет заголовка / нет колонок `turn` или `player`;
- неизвестный ключ метаданных или неизвестная колонка;
- нечисловое значение метрики, нецелый `turn`, пустое имя игрока в строке;
- запись ссылается на игрока, не объявленного в `# player`;
- дубль пары (ход, игрок); отрицательный номер хода; нет ни одного игрока.

Содержательные проверки (баланс городов, всплески дохода и т.п.) —
предупреждения, файл не отклоняют; см. `validation.py` и панель проверки.

## 3. Пример

```csv
# title: Матч с друзьями
# date: 2026-11-12
# mode: Domination
# map: Large · Continent
# link: https://share.polytopia.io/g/a4d531fd-1b81-428c-d81f-08dae2baaab2
# turn_limit: 30
# player: koffeny301; Vengir; #e6194B; human
# player: Wolf_Star; Bardur; #4363d8
turn,player,score,income,army,cities,kills,losses,captured,lost_cities,damage
1,koffeny301,120,5,2,1,0,0,0,0,0
1,Wolf_Star,115,5,2,1,0,0,0,0,0
2,koffeny301,180,7,3,1,1,0,0,0,40
2,Wolf_Star,160,6,2,1,0,1,0,0,0
30,koffeny301,3480,42,18,7,14,6,3,1,5200
30,Wolf_Star,3068,38,15,6,11,9,2,2,4800
```

Пустая ячейка намеренно выглядит так: `2,Wolf_Star,160,,2,1,,,,,` —
доход неизвестен, остальные метрики записаны.

## 4. Round-trip и шаблон

- `polytopia-analyzer template --players A,B --turns 30 -o match.csv`
  создаёт заготовку: все ходы пусты (строки игнорируются при загрузке,
  пока не заполнена хотя бы одна метрика).
- Экспорт (`convert`, кнопка CSV в веб-интерфейсе) пишет только заполненные
  метрики; целые float печатаются без `.0` (`520.0` → `520`); строки
  сортируются по (ход, игрок) — порядок строк может отличаться от исходного
  файла, данные при этом не меняются (проверено round-trip тестом).
- JSON — равноправный формат (`data/*.json`), те же поля и правила;
  веб-интерфейс сохраняет в JSON, CSV удобен для правки в таблице.
