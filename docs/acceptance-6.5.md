# Приёмка 6.5 — реплей целиком

Дата: 2026-11-13. Стенд: Polytopia 2.18.0.16751 (нативная Linux-сборка), Steam,
реплей `share.polytopia.io/g/35b44c27-a0a2-4f52-3290-08df4019957a` (Timeless Battles).

Проверялся весь путь так, как его пройдёт игрок: включить чтение → открыть реплей
по ссылке → программа сама собирает матч → отчёт.

## Протокол

```bash
polytopia-analyzer install-shim enable --restart-steam   # строка запуска в Steam
polytopia-analyzer import-inbox --watch \
    -o data/accept-65.json --title "Timeless Battles" --mode Might --map Archipelago
xdg-open 'steam://run/874390//opengame?id=35b44c27-…'    # реплей из ссылки
```

## Сверка с OCR-эталоном (`data/timeless-battles.json`)

Точных совпадений мало (2 из 20), и это ожидаемо: эталон снят OCR с анимированного
HUD, часть строк привязана не тому игроку (в реплее панель показывает то одного,
то другого). Расхождения — единицы процентов и в обе стороны. Состояние игры даёт
точные значения, поэтому основным источником истины считается оно.

## Что нашлось на приёмке

- **Баг:** `import-inbox --watch` выходил с ошибкой, если папка была пуста
  (запускаешь до реплея — и он падал). Исправлено: режим наблюдения теперь ждёт
  первого снимка. Это тот случай, ради которого `--watch` и нужен.
- Ход 0 иногда фиксируется чуть раньше применения дохода: в одном прогоне счёт
  Goylem был 615 вместо 625. На остальных ходах значения стабильны.
- `LD_PRELOAD` в строке запуска заменяет предзагрузку Steam-оверлея — оверлей
  в игре не работает, пока чтение включено.
- Дамп нельзя включать в живом матче (это чтение чужого состояния). Фильтр
  «только реплей» пока не сделан — до его появления установку лучше держать
  выключенной вне сеансов разбора.
