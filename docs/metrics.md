# Метрики матча: определения и где смотреть в игре

Справочник для ручного ввода (таблица или «Мастер» в веб-интерфейсе).
Девять метрик делятся на два типа:

- **снимок** — значение НА КОНЕЦ хода (score, income, army, cities);
- **прирост** — событие ЗА ход (kills, losses, captured, lost_cities, damage).

Пустая ячейка = «неизвестно», а не ноль. Валидатор различает эти случаи:
правила согласованности срабатывают только на реально заполненных ячейках.

## Таблица метрик

| Метрика | Определение | Где смотреть в игре | Когда записывать |
|---|---|---|---|
| `score` | очки (общая стоимость империи) | экран счёта: в конце матча — итоговое табло; в реплее — экран счёта игроков | конец хода |
| `income` | доход, ☆ за ход | верхняя панель: звёзды и прирост «+N» | конец хода |
| `army` | число юнитов игрока | посчитать юнитов на карте (или список юнитов в реплее) | конец хода |
| `cities` | число городов игрока | посчитать города на карте | конец хода |
| `kills` | убито вражеских юнитов | бои по ходу просмотра реплея | за ход |
| `losses` | потеряно своих юнитов | бои по ходу просмотра реплея | за ход |
| `captured` | захвачено городов/деревень | момент захвата в реплее | за ход |
| `lost_cities` | потеряно городов | момент потери города в реплее | за ход |
| `damage` | нанесённый урон | в обычном интерфейсе НЕ показывается | только если знаете точно |

## Пояснения

### score
В режиме Perfection счёт виден на итоговом табло. Из чего он складывается
(формулы вики, используются для расчёта при автоимпорте):
города 100 + 50×(уровень−1), территория 20/тайл, юниты 5×стоимость,
технологии 100/тир, храмы, монументы 400, парки 250.
В ручном вводе проще снимать готовое число с экрана счёта.

### income
«+N» на верхней панели — сколько звёзд игрок получит в начале следующего
хода. Записывайте то, что видите на конец хода.

### army / cities
Считаются по карте. В реплее удобно ставить паузу в конце хода и считать.
Если юнитов много, можно считать только сухопутные/морские отдельно —
но в поле `army` идёт общее число.

### kills / losses / captured / lost_cities
Счётчиков этих событий в интерфейсе игры нет — ведите подсчёт по ходу
просмотра реплея (пауза после каждого боя/захвата). Роспуск юнита —
не потеря (`losses`): потери — только уничтожение в бою.

### damage
Поле для продвинутого учёта: суммарный урон, нанесённый юнитами игрока
за ход. Ванильный интерфейс его не показывает; заполняйте, только если
считаете вручную или получаете из мода. Пустое значение честнее нуля.

## Правила согласованности (что проверяет валидатор)

- `cities(t) − cities(t−1) = captured(t) − lost_cities(t)` — баланс городов
  (предупреждение W_CITY_BALANCE при расхождении);
- `kills > 0` при заполненном `damage = 0` — подозрительно (W_KILL_NO_DAMAGE);
- падение `score` без `losses`/`lost_cities` за ход — W_SCORE_DROP_UNEXPLAINED;
- `income(t) > 2×income(t−1) + 3` — скачок дохода (W_INCOME_SPIKE);
- прирост `army` за ход больше `income` за ход — W_ARMY_SPIKE.

Предупреждения не блокируют сохранение: их можно принять кнопкой
«✓ Принять предупреждения» (в метаданных появится `verified`).

## Мастер ввода

В веб-интерфейсе переключатель «Таблица / Мастер» показывает карточку
одного хода: все игроки × 9 полей. Клавиатура:

- Enter — следующее поле, Shift+Enter — предыдущее;
- Ctrl+Enter — следующий ход, Ctrl+Shift+Enter — предыдущий;
- Esc — вернуться к таблице.

Данные мастера и таблицы — одни и те же (общий recMap); переключение
вида ничего не теряет. Кнопка «?» в мастере открывает эту справку
в сокращённом виде.
